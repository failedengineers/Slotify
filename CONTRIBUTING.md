# Contributing

Thanks for helping improve Slotify.

## Development

Run the test suite before submitting a change:

~~~bash
python -m pytest
~~~

Add or update tests for behavior changes.

Public API changes should be documented.

Keep examples copyable and avoid documenting behavior that is not implemented.

## Pull requests

Describe what changed, why it changed, tests added or updated, and any compatibility impact.

Never include secrets or private credentials.
