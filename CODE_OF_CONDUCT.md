# Code of Conduct

## Our standard

We want Slotify to be a welcoming project for people with different backgrounds and experience levels.

Be respectful, assume good intentions, and keep technical discussions focused on improving the project.

## Expected behavior

- Use respectful and professional language.
- Explain disagreements with technical reasoning.
- Give constructive feedback.
- Respect different experience levels and perspectives.

## Unacceptable behavior

- Harassment, threats, personal attacks, or discrimination.
- Publishing private information without permission.
- Deliberately disrupting project discussions or contributions.

## Maintainers

Project maintainers may remove comments, close discussions, or take other reasonable action when behavior does not follow this code.

For sensitive concerns, use the repository's private security reporting mechanism when appropriate.
