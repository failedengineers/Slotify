# Support

## Questions and usage help

For usage questions, open a GitHub issue with:

- Slotify version
- Python version
- operating system
- timezone, if relevant
- a small reproducible example
- expected and actual behavior

For common patterns, start with the [documentation](https://failedengineers.github.io/Slotify/).

## Bug reports

Use the [bug report template](https://github.com/failedengineers/Slotify/issues/new?template=bug_report.md).

Please include the smallest reproduction you can.

## Feature requests

Use the [feature request template](https://github.com/failedengineers/Slotify/issues/new?template=feature_request.md) and explain the scheduling problem you need to solve.

## Security

Do not post credentials, API keys, access tokens, or security vulnerabilities in public issues. See [SECURITY.md](SECURITY.md).
